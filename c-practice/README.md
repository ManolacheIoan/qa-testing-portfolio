# C Practice

Basic C exercises demonstrating foundational knowledge from university
coursework: functions, conditionals, loops, and basic I/O.

## basics.c

- `max(a, b)` — returns the larger of two integers
- `is_even(n)` — returns 1 if n is even, 0 if odd
- `sum_to_n(n)` — returns the sum of all integers from 1 to n

Compile and run:
```bash
gcc basics.c -o basics
./basics
```
